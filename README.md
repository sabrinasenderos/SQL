# 🗄️ Prácticas y Ejercicios de SQL (MySQL)

Este repositorio contiene las notas, scripts y ejercicios prácticos de **SQL y Bases de Datos Relacionales** desarrollados en **Visual Studio Code** y gestionados con **MySQL Workbench / MySQL Server**.

## 🎯 Objetivo
Fortalecer las bases sobre diseño, administración y consulta de bases de datos relacionales para aplicar estos conocimientos en entornos de desarrollo real.

---

## 📚 Contenido del Repositorio

- **`01_Reading/`**: Consultas básicas y avanzadas (`SELECT`, `WHERE`, `ORDER BY`, `LIKE`, `GROUP BY`, `HAVING`).
- **`02_Writing/`**: Insertar, actualizar y eliminar datos (`INSERT INTO`, `UPDATE`, `DELETE`).
- **`03_Tables/`**: Creación y modificación de tablas (`CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`).
- **`04_Database/`**: Gestión de bases de datos y esquemas.
- **`05_Join/`**: Relación entre tablas (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
- **`06_Advanced/`**: Conceptos avanzados (Índices, Triggers, Vistas, Procedimientos Almacenados).

---

## 🛠️ Tecnologías Utilizadas

- **SGBD:** MySQL 8.0
- **Entorno de Desarrollo:** Visual Studio Code (Extensiones de MySQL / Database Client)
- **Control de Versiones:** Git & GitHub
